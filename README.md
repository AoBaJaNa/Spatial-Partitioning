# Spatial Partitioning

Unity RTS unit environment reused as a minimal project for spatial-partitioning research.

## Environment

- Unity 6000.3.10f1
- URP 17.3.0
- Input System 1.18.0

## Open

Open `Assets/SpatialPartition/Scenes/SpatialPartitionSandbox.unity`.

## Asset layout

- `Assets/SpatialPartition/Scenes`: research scenes
- `Assets/SpatialPartition/Scripts`: research and minimal reused runtime code
- `Assets/SpatialPartition/Editor`: research editor tools
- `Assets/SpatialPartition/Prefabs`: unit prefab
- `Assets/SpatialPartition/Materials`: required materials

Large RTS benchmark scenes and unrelated RTS project files are intentionally excluded.
